# CalcXpert

CalcXpert is a collection of simple, fast, and useful online calculators and utility tools designed to help users perform everyday calculations easily.

The project focuses on providing lightweight tools with a clean interface, responsive design, and easy-to-understand results.

## Features

- Multiple online calculators
- Unit conversion tools
- Responsive design
- Mobile-friendly interface
- Fast loading pages
- Simple and minimal UI
- SEO-friendly pages
- Easy navigation
- Lightweight implementation

## Available Tools

Some of the tools included or planned for CalcXpert:

- BMI Calculator

More tools will be added over time.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/calcxpert-tools.git
````

Move into the project directory:

```bash
cd calcxpert-tools
```

Install dependencies:

```bash
composer install
```

Copy the environment file:

```bash
cp env .env
```

Run the development server:

```bash
php spark serve
```

Open:

```text
http://localhost:8080
```
